# Clone Service Page Templates

These folders contain reusable service page templates for Oracle HCM, Oracle SCM, and Oracle Financials.

## What is included

- Full page structure for hero, sections, cards, and CTA
- Content copied from the original site
- Minimal image dependency so another project can adapt it easily
- Clean class names that an AI editor can understand and style

## How to use

1. Copy the relevant folder into another project.
2. Import the page component into the router.
3. Add the shared CSS file from the target project or adapt the class names.
4. Replace the theme colors and typography to fit the new website.

## Notes for AI agents

- Preserve the section order and content structure.
- Keep the hero, section headings, cards, and CTA intact.
- Update styling based on the target website theme.
- Avoid adding unnecessary image assets unless required.
